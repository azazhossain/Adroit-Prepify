# Adroit Prepify

Offline-first Android study app for mastering appropriate prepositions, built from the supplied workbook and previous-year question PDF.

## Build and release the APK

Open **Actions → Build Adroit Prepify APK → Run workflow**, then download the `adroit-prepify-release` artifact or the APK attached to the generated GitHub Release. A build is also triggered automatically on pushes to `main`.

## Optimised study experience

- Four selectable colour palettes: Sky blue, Emerald green, Amber, and Violet.
- System, light, and dark appearance modes with high-contrast text and accessible surfaces.
- Flashcards support animated swipe navigation: swipe right for the previous word and swipe left for the next word.
- Workbook MCQs use only preposition options.
- Answers and explanations appear after the user selects an option.
- Previous-year board and admission questions are parsed into a dedicated quiz with part filters and answer explanations.

The app stores study progress, memorized words, bookmarks, mistakes, streaks, and settings locally on the device.
